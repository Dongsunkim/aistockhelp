# StockDesk · 매수 시점 요약 · 데이터 검증 우선 버전 0.4.3

이 저장소는 이전 StockDesk v0.4.0 소스 백업에서 복원한 **부분 복구판**입니다. 이전 프로젝트의 v0.5.4 전체 기능이 그대로 이전된 것이 아닙니다.

- 국내 네이버증권 비공식 확정 OHLCV: 네이버 FCHART → 네이버 모바일 JSON 대체. **Yahoo 국내 대체 금지**
- 미국 Yahoo Finance 비공식 확정 일봉, 국내 네이버 비공식 현재가 참고
- 지표: 이동평균 SMA20/60/120, RSI14, ATR14, 거래량, 거래 위험, 기술적 백테스트
- 국내 네이버증권 종목뉴스·리서치 목록·기업실적분석 우선 조회. 실패하면 기사 RSS / DART 수치를 대체 출처로 명시
- DART/SEC 공식 공시 및 재무 주요계정 대조 자료. 재무 검증이 미완료여도 유효한 기술적 가격대는 참고용으로 표시하며, 매수 판단은 보류
- 첫 화면은 한 줄 판단·핵심 이유·다시 확인할 시점을 표시. 가격대·차트·뉴스·검증 근거는 상세 보기로 제공
- 18px 맑은 고딕 중심 가독성, 데이터 품질·경고 노출
- 일봉 출처·기준일·가격관계에 문제가 있으면 기술적 가격대를 숨기고 사유 표시
- **확정매수/자동주문 기능 없음**. 조건이 갖춰져도 매수 관찰 후보로만 표시합니다. 기사·리서치 목록은 원문 내용 분석과 구분합니다. 내재가치 평가 및 증권사 원문 검증 기능은 복구 전입니다.
- 중요: 네이버 비공식 API 구조는 변경될 수 있습니다. 응답을 검증하지 못하면 오류를 반환합니다.

실행: `pip install -r requirements.txt` 후 `uvicorn app:app --reload`. 테스트: `python -m pytest -q`, `node --test tests/*.cjs`.

OpenDART와 SEC API 키는 Vercel 환경변수로만 제공하고 GitHub에 커밋하지 마세요.

Vercel에서 DART 인증키는 `DART_API_KEY`(권장) 또는 `DART_API`(기존 프로젝트 호환)로 설정합니다. 실제 값은 GitHub에 올리지 않습니다.

네이버 연동 검증: HTML 파서는 단위(억원→원), 확정 실적/예상치, 회계기간과 링크를 검사합니다. 네이버 응답 구조가 바뀌면 오류로 처리하고 대체 출처를 표시합니다. 실제 최신 응답에 대한 연결 검증은 네이버 도메인 접속 허용이 필요합니다.

- 미국 경제·시장 필수 점검: FRED 실효 연방기금금리·원달러·CPI와 S&P500·나스닥·반도체 지수, NVDA/AAPL/MSFT의 확정 일봉을 함께 확인합니다. 누락·오래된 자료는 매수 관찰 후보 판정을 막습니다. 위험 임계값은 운영 가정이며 예측 모델이 아닙니다. 성공한 공통 자료만 60초 캐시하고 기준일을 표시합니다.
- 작은 종목 질문창: `OPENAI_API_KEY`가 서버에 설정되면 질문할 때만 Responses API를 호출합니다. 키가 없으면 AI 미연결을 표시하고 실제 수집 자료로 한정한 안내를 제공합니다. 원문을 읽었다고 주장하지 않으며 출처 링크를 표시합니다. 공개 질문 제한은 IP당 분당 6회·프로세스 전체 24회인 최선형 보호로, 서버리스 전체의 과금 한도를 보장하지 않습니다.

## DART 공시·전체 재무제표 조회

화면의 **DART 공시·재무 조회**에서 국내 6자리 종목코드, 사업연도, 보고서, 연결/별도를 선택합니다. 시세 분석과 독립적으로 동작하므로 네이버 일봉을 수집하지 못해도 DART 자료를 조회할 수 있습니다.

- 전체 재무제표 API `fnlttSinglAcntAll.json`이 제공하는 모든 계정을 가져옵니다. 재무상태표(BS), 손익계산서(IS), 포괄손익계산서(CIS), 현금흐름표(CF), 자본변동표(SCE)는 회사와 보고서에 따라 제공 범위가 다릅니다. 없는 표나 계정을 임의로 만들지 않습니다.
- 연결(CFS)과 별도(OFS)를 구분하고, 당기·전기·전전기 및 분기/반기 누적 금액과 공시 통화·접수번호 등 원본 필드를 보존합니다. 큰 금액은 문자열 그대로 표시·JSON 저장하여 자바스크립트 정수 반올림을 피합니다.
- `list.json`으로 조회기간의 모든 공시 유형을 검색합니다. 기간은 한 번에 최대 366일이며 페이지당 100건입니다. 조회 건수와 전체 건수를 구분하고 추가 페이지 또는 전체 공시를 불러올 수 있습니다. 정정 여부·제출인 등 DART 메타데이터와 원문 뷰어 링크를 보존합니다. 공시 본문 전문을 자동 분석한 결과는 아닙니다.
- 사업연도는 2015년부터 선택할 수 있으며 사업보고서 `11011`, 1분기 `11013`, 반기 `11012`, 3분기 `11014`를 지원합니다. 미공시 보고서, 미제공 재무제표와 조회 실패를 구분합니다. 과거 사업연도는 다시 선택하여 조회합니다.

서버 API:

```text
POST /api/dart/financials
{"symbol":"005930","year":2025,"report_code":"11011","fs_div":"BOTH"}

POST /api/dart/disclosures
{"symbol":"005930","begin":"2025-01-01","end":"2025-12-31","page":1}
```

검증은 `python -m pytest -q`와 `node tests/dart_ui_smoke.cjs`로 실행합니다. DART 응답을 모의하여 전체 계정·페이지, 오류 처리와 브라우저 금액 정밀도를 검사하며 실제 키 없이 실행할 수 있습니다.

인증키는 서버 환경변수 `DART_API_KEY` 또는 기존 `DART_API`로만 전달합니다. 브라우저 입력이나 요청 본문에 넣지 않습니다. 클라우드 환경에서는 환경 설정의 보안 입력란에 등록하고 `opendart.fss.or.kr`의 HTTPS 접근을 허용해야 합니다. 저장된 설정 초안만으로 현재 실행 환경에 적용되지는 않습니다. 키가 없으면 API는 503, 잘못된 입력은 422, 외부 조회 실패는 502를 반환합니다.

기존 가격 분석의 핵심 재무계정 3개와 품질검증은 유지합니다. 전체 재무제표는 별도 응답으로 제공하여 여러 기간·연결/별도 계정을 뒤섞거나 전체 자료를 AI 요약에 보내지 않습니다. OpenDART가 제공하는 재무제표 계정의 범위이며, 모든 부가정보 API·주석·원문 보고서 전문을 수집한다는 의미는 아닙니다.

## 분석 응답 속도

웹 화면은 `/api/analyze/stream`으로 차트 계산부터 표시하고, 기사·공시·재무·미국 경제 자료가 도착하는 대로 갱신합니다. 필수 근거가 확인되기 전에는 종합 판단을 확정하지 않습니다. 핵심 근거 확인이 끝나면 리서치·참고 현재가를 기다리지 않고 판단을 먼저 보여주며, AI 질문은 전체 자료 확인 후 열립니다. 연결이 중단되면 일부 자료만 확인된 상태를 명시합니다. 기존 `/api/analyze` JSON 응답은 유지합니다.

완료된 분석과 검증된 국내 일봉은 프로세스에서 30초 동안만 재사용합니다. 부분 응답과 제공원 오류는 완료 분석으로 캐시하지 않으며, 원래 조회시각과 관측 기준일을 유지합니다. 캐시는 서버리스 인스턴스별이므로 첫 요청·새 인스턴스에서는 외부 조회가 필요합니다. 네이버 모바일 일봉 대체 조회는 동일한20개/페이지와330개·1000개 기록을 유지하면서 최대4개 요청을 함께 처리합니다. FRED는 필요한 기간만 조회하되 CPI의 정확한 전년 동월과 직전 월 비교값은 모두 유지합니다.
